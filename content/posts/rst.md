## Idea
It was my first project that I could save. I made it in 8th grade. It was made for monitoring Linux systems using easy telegram-bot interface. It used python-telegram-bot, psutil and speedtest-cli(when it worked in Russia, lol). It had some features such as CPU, RAM monitoring, network speedtest, showing information about system.
